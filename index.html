¿Cómo funciona DOUBLEPLAY?

🎵 Reproducción de Música Real

Sube tus propias canciones desde el dispositivo. El reproductor usa la Web Audio API del navegador para reproducir archivos MP3, WAV, OGG, FLAC y más. La duración se detecta automáticamente del archivo.

🔗 ¿Qué es una Lista Doblemente Enlazada?

Una lista doblemente enlazada es una estructura de datos donde cada nodo contiene información y referencias bidireccionales: al nodo anterior y al nodo siguiente.

✅ Ventajas sobre un Array

  • Navegación bidireccional: se puede avanzar y retroceder usando punteros.
  • Inserción eficiente: agregar al inicio, final o posición sin desplazar elementos.
  • Eliminación eficiente: eliminar un nodo solo requiere actualizar dos punteros.
  • Sin tamaño fijo: crece dinámicamente según sea necesario.

🎵 Cómo se usa en DOUBLEPLAY

  • Siguiente → ejecuta current = current.next
  • ← Anterior ejecuta current = current.previous
  • Agregar al inicio crea un nuevo nodo como cabeza
  • Agregar al final crea un nuevo nodo como cola
  • Eliminar reconnecta los punteros del nodo anterior y siguiente
